# 국가기술자격 Q-Page 자격정보집

국가기술자격 652종목(검정형 545 · 과정평가형 107)의 응시·취득·취업·임금 통계를
종목당 한 화면으로 제공하는 대국민 채널.
다이렉트 링크 : <https://gjtjdwns1008-dev.github.io/hrdk-q-page/>

화면 자료는 **내부망 엑셀 원장(Q-PAGE)**이 만들고, 우대법령만 **법령 네비게이터**가
매일 게시하는 자료를 배포 시점에 덧입힌다. 저장소에 올라온 HTML 원본은 어떤 경우에도
수정되지 않는다.

## 구조

```
q-page-outside_YYYY-MM-DD.html      외부공개 화면(단일 파일, 자료 내장).
                                    날짜가 가장 최신인 파일이 자동으로 홈(index)에 배포된다.
pdf/                                종목별 화면 PDF. 파일명 = 종목코드.pdf (외부용 시트 출력물만)
tools/
  pdf_to_png.py                     pdf/ → PNG 변환기 (pdftoppm+pngquant, 없으면 PyMuPDF 폴백)
  pref_inject.py                    우대법령 오버레이 주입기 (게시 JSON → 배포본에만 주입)
robots.txt                          검색엔진 수집 차단(시범 기간). 공식 전환 때 삭제.
.github/workflows/
  build-qpage.yml                   배포 지시서: 최신 외부공개본을 홈으로 배포
  keepalive.yml                     월 1회 심장박동(저장소 활동 유지용 커밋)
```

## 배포가 도는 시점 (v4)

- `q-page-outside_*.html` 이 올라올 때 **한 번** 돈다.
- **매일 05:23(한국시간) 자동 1회** — 법령 네비게이터가 게시하는 우대법령
  (pref_export.json) 최신본을 홈 화면에 주입해 재배포한다. 주입 검산이 실패하면
  순정본 그대로 배포(안전).
- **pdf/ 업로드는 배포를 일으키지 않는다.** 깃허브 웹은 한 번에 100개까지만
  올라가므로 PDF를 여러 번 나눠 올려도 조용하다. 다 올린 뒤 HTML을 올리면
  그때 한 번만 돌고, HTML 변경 없이 PDF만 갱신했다면 Actions 탭에서
  수동 실행(Run workflow) 한 번.
- 삭제 커밋: 깃허브 감시는 삭제에도 이벤트를 띄우지만, 문지기(gate)가
  "삭제만 있는 커밋"이면 10초 만에 본작업을 생략한다(변환·배포 없음).
  최신본을 지워 이전 날짜본으로 되돌리려면 수동 실행(Run workflow) 1회.

## 우대법령 연계 (법령 네비게이터)

- 화면의 「우대법령 N건」 칩과 「법령 우대 현황」 구역은 **엑셀 원장에 없는 자료**다.
  배포 워크플로가 매일 아래 순서로 덧입힌다.
  1. 화면에 내장된 **명찰**(`<script id="qpage-master">` — 기준연도와 수록 종목코드·명칭)을 읽는다
  2. 법령 네비게이터가 게시한 `pref_export.json` 을 받아 검산한다
     (건수 등식 · 성격 표기 · 대표 3건 이하 · 기준일 형식 · 신선도 35일)
  3. 검산을 통과하면 배포본에만 `pref_law` 를 주입한다. 하나라도 실패하면
     **주입을 건너뛰고 순정본을 배포**하며 Actions 요약에 경고를 남긴다
- 「자세히 보기」 버튼은 그 종목의 법령 네비게이터 카드로 직행한다
  (`.../hrdk-q-radar/#/q/종목코드`). 과정평가형은 동명 검정형 코드로 치환해 보낸다.
- 원장에는 우대법령을 넣지 않는다(내부망·외부망 분리). 화면 자료의 정본은 게시 JSON,
  연 1회 받는 CSV는 그해 스냅샷 보존용이다.
- 자료가 없거나 검산에 걸리면 **칩·구역이 통째로 숨는다.** 잘못된 숫자가 표시되는
  경우는 설계상 없다.

## 공개 범위 정책

- **심의 경과·사유를 적은 필드는 대외 공개 대상이 아니다.**
  종목마스터의 `개편결과_종합`·`개편연도_법령` 이 여기 해당한다
  (예: 개편 보류 사유, 관련 단체·부처 반대, 민원 경위).
- 차단 장치는 세 겹이다.
  1. **Z33 v1.6** — 두 필드를 내부용 화면에만 싣는다(`P0` 배선). 외부용 자료에는
     애초에 들어가지 않는다. `P`(양쪽 출력)로 되돌리면 즉시 유출이므로 손대지 말 것.
  2. **반출 검문** — 외부공개 HTML 생성 직전에 자료를 훑어 `개편·민원·보류·미적용`
     이 발견되면 **생성을 중단**한다. 원장 텍스트를 고치거나 정책을 먼저 정리할 것.
  3. **내부용 침입 차단** — `q-page-inside*` / `*내부용*.html` 이 저장소에서 발견되면
     배포가 강제 중단된다.
- PDF도 같은 원칙이다. `pdf/` 에는 **외부용 시트 출력물만** 올린다.
  외부용 시트 배선(Z34)에는 공개 금지 셀 목록이 있어 재실행해도 금지 항목이
  들어오지 않는다.
- 사이트의 PNG는 이 PDF를 그림으로 변환한 것이다. **PDF에 있는 내용은 그림으로도
  공개된다**는 점을 항상 함께 판단할 것.

## 규약·안전장치

- `dist/` 와 PNG는 커밋하지 않는다(Actions 빌드 산출물).
  변환된 PNG 주소: `https://<계정>.github.io/<저장소>/sheets/종목코드.png`
- 과거 날짜의 `q-page-outside_*.html` 은 지우지 않아도 된다(연도별 보관함).
- **keepalive**: 갱신이 연 1회라 저장소가 오래 조용하면 깃허브가 예약
  워크플로를 끈다(60일 규정). 월 1회 날짜 파일 커밋으로 활동을 유지한다.
- 저장소는 공개다. **한 번 올린 파일은 이후 지워도 커밋 이력에 남는다.**
  올리기 전에 공개 범위를 확인할 것.

## 연간 갱신 순서

1. 엑셀: 새 연도 파일 만들기 → 입력파일 내보내기 → 불러오기 → 순위·평균 다시 계산
2. One-page(외부용) 시트에서 종목별 PDF 일괄 생성 → `pdf/` 에 **먼저** 업로드
   (100개씩 나눠 올려도 됨 — 이 단계에서는 배포가 돌지 않는다)
3. 리본 **[외부공개 HTML]** → `out\q-page-outside_날짜.html` 생성
   (반출 검문에 걸리면 생성이 중단된다 — 원장을 정리한 뒤 다시 실행)
4. 그 파일을 저장소 루트에 **마지막으로** 업로드 → 배포가 한 번 돌며 전부 반영
5. Actions 요약에서 확인할 것
   - 「배포 산출물」의 홈(index) 파일명이 방금 올린 파일인지
   - 「화면 PNG 변환」 실패 0건
   - 「우대법령 오버레이」 주입 종목 수와 기준일
6. 사이트 하단 배너의 **생성 날짜**가 새 파일 날짜인지 확인(배포 성공 여부 계기판)

## 생성물 자가 점검 (메모장 Ctrl+F)

| 찾을 문자열 | 의미 |
|---|---|
| `qpage-master` | 명찰 내장 — 우대법령 주입 가능 상태 |
| `"built":"날짜"` | 엑셀이 그 날짜에 만든 파일 |
| `개편` | **하나라도 나오면 외부 배포 금지** (반출 검문을 우회한 상태) |

## 사전 1회 설정

깃허브 웹에서 Settings → Pages → Source = **GitHub Actions** 로 지정.
그 외 설정·비밀키 없음. 외부 연계는 공개 게시물만 읽으므로 인증 정보를 저장하지 않는다.

※ 저장소 이름을 바꾸면 **게시 주소도 함께 바뀌고 옛 주소는 404가 된다**
(깃허브 저장소 주소는 자동 연결되지만 사이트 주소는 연결되지 않는다).
